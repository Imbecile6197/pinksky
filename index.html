PinkSky

Nativní GNOME klient pro Bluesky a Mastodon

Instalace

Nainstalovat PinkSky

Otevře se v aplikaci Software. Nebo v terminálu:

flatpak install --user https://imbecile6197.github.io/pinksky/pinksky.flatpakref

Aktualizace pak instaluje aplikace Software, příkaz flatpak update, nebo sám PinkSky.

Installation

Click the button above to install with Software, or run the command in a terminal. Updates are installed by Software, by flatpak update, or by PinkSky itself.
